# Nothing special. Just another website.

Project cards live in `index.html`, inside `#projects-track`. Put new or stronger
work at the beginning of that list and move older work toward the end. The slider
uses the list order and adjusts to the number of cards automatically.

Use a recognizable subject image for each cover. Keep its short description and
skill tags, link to the working project or report, and add a separate Preview link
when a screenshot helps visitors inspect the work.
